# Pack quality check (before showing a pack to the owner)

- [ ] One exception id from `register.py`, never reused or invented.
- [ ] Class is factual; "suspected" wherever a concern is not proven; no person named as responsible.
- [ ] Every fact cites a file and row or page; nothing is paraphrased as fact that the record does not say.
- [ ] The mismatch or missing fact is stated exactly.
- [ ] Amount stated; materiality claimed only against an owner-supplied threshold or a qualitative trigger.
- [ ] Work done and why it did not settle the item.
- [ ] Deadline only if a source proves it.
- [ ] Exactly one decision request and one named owner; owner-delegate path used if the usual approver is involved.
- [ ] Safe interim state is something this assistant can actually do (leave unresolved, pause a draft) or recommends to the owner.
- [ ] For a bank-detail change: the verification contact is from records dated before the change; nothing from the request itself; no web lookup; no payment drafted to the new details.
- [ ] `build_pack.py` ran: cited rows only, withheld fields listed, numbers masked to the last 4 digits.
- [ ] The pack is a draft; the recipient is named and not yet sent to.
- [ ] Original records unchanged; nothing posted, reversed, or deleted.
