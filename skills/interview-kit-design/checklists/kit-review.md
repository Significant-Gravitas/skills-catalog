# Kit review (before coordination books the loop)

- [ ] Every must-have from the role scorecard has exactly one owner slot
      (`check_kit.py` exit 0).
- [ ] Knockout competencies sit early; room-to-explain topics (career change,
      gaps) sit in a later slot; the hiring manager's close is last.
- [ ] Four slots or fewer, or the reason for more is written in the kit.
- [ ] 4-6 core questions per slot, each with a strong-answer note and an
      ownership probe.
- [ ] `question_lint.py` exit 0 on the kit and on the owner's own questions;
      every rewrite shown in "Dropped or rewritten".
- [ ] Each clock adds up to the slot length and keeps time for the
      candidate's questions.
- [ ] Anchors 1-5 plus "not assessed" for every owned competency, in this
      role's real work; draft anchors marked draft.
- [ ] Scorecard: hire / no-hire last, after every rating; no affect, no
      "fit", no polish.
- [ ] Accommodation contact named; candidate AI-use policy recorded or
      "no policy set" flagged.
- [ ] AI-law line added if the role is in NYC, Illinois, California or the EU.
- [ ] Slots missing an interviewer or a competency named in one line.
- [ ] Kit saved to `~/workspace/hiring/roles/<role-slug>/kit.md` and delivered.

# Packet pass (evening before)

- [ ] `build_packets.py` run for the date; every FLAG reported.
- [ ] Summary: at most five direct quotes, each sourced; `verify_quotes.py`
      exit 0 (every line OK or "not stated"), SKIPs marked UNVERIFIED in the packet.
- [ ] Times in the candidate's zone and the owner's; UNKNOWN never guessed.
- [ ] No protected characteristic anywhere; no ranking or comparison of candidates.
- [ ] Packets delivered to the owner; nothing sent to the panel without a yes.
