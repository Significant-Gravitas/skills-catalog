# Question bank: <role> (rubric v<n>)

One block per question. Every question maps to exactly one rubric criterion.
Every candidate gets the same core questions in the same slot and the same
time. Follow-ups clarify the candidate's own answer; they never add a
criterion [19][27].

Question types and when to use each: `references/question-bank-patterns.md`.
Run `scripts/question_lint.py` on this file before it goes to the owner.

---

### Ability requirements (only if the role has them)
Ask every candidate in the same words, and only for a real job requirement
stated in the approved role:
- "This role requires <function, e.g. lifting 20 kg boxes / weekend on-call one week in four>. Can you perform that, with or without reasonable accommodation?" [35][46]

### Work authorisation (only if the owner's process asks it at interview)
- "Are you legally authorised to work in <country>?" / "Will you now or in the future require sponsorship?" (yes/no only; wording from the owner's template) [34]
