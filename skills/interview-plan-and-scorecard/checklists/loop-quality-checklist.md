# Loop quality checklist

Mirror this in `TodoWrite` for a first loop. Tick every line before the plan
goes to the owner. `[n]` citations are in `references/sources.md`.

## Before planning
- [ ] The rubric is approved (name and date recorded). If not, stop and route to hiring-rubric-design.
- [ ] The rubric is saved as `~/workspace/hiring/<role-slug>/rubric.csv` with anchors copied verbatim.
- [ ] Interviewers, coordinator and accommodation contact are named, or listed as missing owners.

## Loop
- [ ] Every criterion has exactly one primary slot (`check_loop.py` OK) [21].
- [ ] No criterion was added because a candidate or interviewer suggested it.
- [ ] Four slots or fewer, or a written reason for each extra slot (default [29]).
- [ ] Slot minutes add up to the stated loop length.
- [ ] Reference checks appear only if company policy allows them.
- [ ] At least two different interviewers across the loop.

## Questions
- [ ] Each question maps to one criterion, with good-evidence and do-not-score notes.
- [ ] Past-behaviour questions for criteria with a track record; situational only where fitting [27].
- [ ] Set follow-ups test ownership and result, the same for everyone [19][24][26].
- [ ] `question_lint.py` run; every hit rewritten or confirmed as a stated job requirement; changes shown to the owner.
- [ ] Physical or schedule requirements use "with or without reasonable accommodation" [35][46].
- [ ] No trick questions, brainteasers or pet questions [23].

## Scorecards
- [ ] Generated by `make_scorecards.py`; no anchor marked missing.
- [ ] Each interviewer's card holds only their criteria.
- [ ] "File before seeing peers" instruction present; no overall or gut-feel field [20][21].
- [ ] No demeanour, confidence, enthusiasm, honesty, affect or fit rows [73][79].

## Candidate note
- [ ] Stages, length and what each covers; same for every candidate.
- [ ] AI-use policy per stage from the owner, or `[OWNER TO CONFIRM]` [104].
- [ ] Accommodation contact named; no medical details requested [35].
- [ ] Decision timing stated or `[OWNER TO CONFIRM]` [80].

## Hand-off
- [ ] Plan saved to `~/workspace/hiring/<role-slug>/interview-plan.md` and delivered with `write_workspace_file`.
- [ ] Nothing invited, sent, scheduled, or changed in a calendar or ATS.
- [ ] Missing-owner list and approval line present.
