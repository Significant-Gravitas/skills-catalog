# Intake sitting checklist

**Before**
- [ ] Existing scorecard? (`cat ~/workspace/hiring/roles/<slug>/scorecard.md`)
- [ ] Preferences read (timezone, jurisdictions, panel, loop shape)
- [ ] Source of the ask: paste / Granola call (owner confirmed which) / Drive doc

**Draft in chat (within the minute)**
- [ ] Mission, 2 lines
- [ ] Year-one outcomes, each with a FACT quote + source or labelled INFERENCE
- [ ] 3-6 must-haves; each objective, non-comparative, job-relevant
- [ ] Each must-have names its evidence method
- [ ] Years/degree floors replaced, or "HM defended: <quote>"
- [ ] Nice-to-haves labelled; disqualifiers in HM's words + fairness check
- [ ] Every proxy rewritten or cut, and you said which
- [ ] Location as work terms; physical demands "with or without reasonable accommodation"
- [ ] Counts written as counts ("over 10 direct reports" is fine; "candidates over 50" is an age limit)
- [ ] A job word the lexicon flags (a daycare's "children aged 3 to 5", a clinic's "medical history records"): `lint_ok: <term> - <why>` under that item, and the WARN read to the HM

**Calibrate and map**
- [ ] Benchmark person? B1..B4-6 transferable traits; incidental dropped
- [ ] Target companies from `web_search`, each fetched, `link_status` set
- [ ] Boundaries: competitors? off-limits companies?
- [ ] 5-10 title variants incl. 2+ dark-matter
- [ ] Evidence sources for the function

**Plan**
- [ ] Stages ordered deal-breakers first; each must-have mapped to one stage
- [ ] Panel and competencies named (only real people)
- [ ] Slate target, fill date: value or UNKNOWN
- [ ] Compensation: who sets it and how; no figure
- [ ] Referral-only? Say the narrowing once
- [ ] Jurisdiction flag line if applicable

**Close**
- [ ] Saved to `~/workspace/hiring/roles/<slug>/scorecard.md` + `target-companies.csv`
- [ ] `scorecard_check.py` exit 0; WARNs shown
- [ ] Copy delivered via `write_workspace_file`, linked
- [ ] Approval stamped only with the HM's quoted yes; an "approver is not the hiring_manager" WARN is resolved first
- [ ] Linear issue only on a yes; roles.csv row only on a yes
