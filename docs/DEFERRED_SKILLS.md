# Deferred researched sources

These 40 sources are preserved for traceability and are excluded from catalog.yml and skills/. They are not installed, executable catalog packages. Their exact original files, licences, hashes and explanations are retained in [deferred-skills.json](../provenance/deferred-skills.json) and content-addressed archives.

## Decisions

- **Advertising suite (34 skills):** even a conservative native dependency set needs 106 supplementary files, exceeding the current 100-file cap. The authored validation/release branches need further fixtures and native layout. Native dispatch and agents also need integration. Splitting off instructions or converting mandatory dependencies to remote links would alter utility, so the complete selected suite is held. The archive retains 335 used/conditional source paths; unused repository material is excluded.
- **Prospecting:** the required GitHub helper exports profile text to CSV without neutralizing formula-like cell prefixes. This was found by source inspection with a harmless static example; the helper was not run or patched. Preserve the original and await an upstream correction or an explicit platform-level solution.
- **Invoice chase:** its controlling licence has ambiguous appended text. The skill was introduced after that change and is absent from the verified clean historical revision. It is excluded pending clarification. Six other affected packages were replaced as whole, exact historical selections whose primary/support bytes match and whose controlling licence is clean.
